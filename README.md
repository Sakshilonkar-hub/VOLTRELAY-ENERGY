# VOLTRELAY-ENERGY
VoltRelay’s battery-swapping network expanded substantially between January 2024 and June 2025. Monthly completed swaps increased from 103,508 to 303,196, while monthly revenue rose from ₹6.20 million to ₹19.69 million. However, network growth was accompanied by a deterioration in reliability: the monthly failure rate increased from 4.4% to 8.6%.
